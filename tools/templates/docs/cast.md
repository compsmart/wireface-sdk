Passages written for docs/characters.md, which tools/docs.mjs builds from the three.js guide to the cast. Each
block starts with a line holding only its name in an HTML comment, and every block must be used.

<!-- intro -->
Eleven ready-made characters in `@wireface/sdk/three/characters`, each showing one way to put a face on a head (see
them all in the [Wireface Theatre](https://wireface.dev/threejs/demo/)).

<!-- start-from -->
Start from the closest member of the cast (its `code` shows how its face is made), or build from the kit,
`@wireface/sdk/three/kit` (see [Building characters](three.md#8-building-characters)).
