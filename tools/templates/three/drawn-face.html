A prepared face on a can

A prepared 2D character painted onto a cylinder. wrapGeometry() curves its animated texture around the can; paintOn() lights it with the metal. The bundled character already contains its rig and needs no network service.

Expressions

const screen = new FaceScreen({ engine: '2d',
  character: 'bolt' });
const can = new THREE.Mesh(
  wrapGeometry(new THREE.CylinderGeometry(0.2, 0.2, 0.32, 64),
    { radius: 0.2, width: 0.3, height: 0.3 }),
  screen.paintOn(new THREE.MeshStandardMaterial({ color })));
head.add(screen.bind(can));
