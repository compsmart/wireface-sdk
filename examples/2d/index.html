Wireface SDK: 2D examples

Each one is a single short HTML file: view its source. Run npm start and open them from there.

  • hello

    The smallest 2D face: a ready-made character that blinks, breathes and smiles.

  • characters

    Every built-in character, in thirteen art styles, burning in and out.

  • expressions

    Every mood, a custom expression made with defineExpression, and the face's states.

  • teeth

    Rendered teeth, photographic and drawn teeth pictures, or none, on the same character.

  • talk

    Recorded lines with their phoneme-aligned mouth tracks: lip sync you can hear.

  • live

    Lip sync from your microphone or any audio file as it plays.

  • detect

    Drop in any picture and watch Gemini Pro and MediaPipe find the face, step by step.

  • generate

    Describe a character, pick an art style: Gemini draws it, and it starts talking.

  • conversation

    A spoken conversation with a character through Gemini Live, with a one-use token.

  • config

    Config files: load, edit, validate, apply.

And the demo, with everything on one page.

The detect, generate and conversation examples need the dev server's API: set GEMINI_API_KEY (or put it in .env) before npm start.
