Styles

One face, four looks, all lit by the same lights: photo (a skin), sculpt (any skin colour), toon (cel-shaded) and hologram (glowing wireframe, made for a bloom pass). The colour presets set the hologram's colours, and the glow of a sweep; skin_amount cross-fades a skin into the wireframe.

Colours

new FaceMesh({ skin: 'arjun' });                   // photo
new FaceMesh({ style: 'sculpt', colors: { skin: '#c68863' } });
new FaceMesh({ style: 'toon', colors: { skin: '#f2b38b' } });
new FaceMesh({ style: 'hologram', preset: 'violet' });
face.set({ skin_amount: 0.5 });          // half wireframe
await face.useSkin('omar', { sweep: 1.4 });
