Lip sync from a microphone

Talk, and the robot says it. face.listenTo() reads the mouth from the sound as it plays (loudness and spectrum, frame by frame), so it works for anything you don't have in advance: a microphone, a WebRTC call, streaming text-to-speech in an <audio> element.

const audioContext = unlockAudio();     // after a click
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
const stop = face.listenTo(audioContext, stream, { gain: 1.2 });
// ...
stop();

Unit-7 comes from the cast: buildCharacter('unit7'). Its chest lights blink with face.level.
