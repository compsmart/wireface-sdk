A face on a screen

A FaceScreen: Wireface core's own renderer draws the face (its glowing wireframe, bloom and all) on a hidden canvas, and that canvas is the texture of a monitor's screen. Turn the monitor and the face follows you.

Colours

Skins

const screen = new FaceScreen({ engine: '3d',
  config: { preset: 'cyan', skin_amount: 0 } });
const glass = new THREE.Mesh(
  screenGeometry({ width: 0.64, height: 0.48, curve: 0.02 }),
  screen.material({ corner: 0.04 }));
monitor.add(screen.bind(glass));   // drawn as it's drawn
screen.gazeAt(camera);
