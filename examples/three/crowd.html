A crowd

Every FaceMesh is ordinary geometry in your one renderer, so there's no limit of WebGL contexts: here are 24 of them, each with its own rig, animator and timeline. Every face costs a little CPU a frame (its 468 vertices posed) and a few draw calls.

for (let i = 0; i < 24; i++) {
  const face = new FaceMesh({ skin: SKINS[i % 11], size: 0.16 });
  face.position.set(x, y, z);          // rows of eight, up and back
  scene.add(face);
}
// one clip, mimed by all (no audioContext: silent)
faces.forEach(f => f.say(clip));
