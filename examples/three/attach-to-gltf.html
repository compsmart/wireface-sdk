A face on a glTF model

A rigged model from a file: findBone() finds its head bone, and attachFace() puts a hologram face on it. The model's own animations play underneath, and the face's nods and turns are added on top of them, so it can wave, dance and talk at once.

Animation

Model: RobotExpressive by Tomás Laulhé (CC0), from the three.js examples.

const robot = (await new GLTFLoader().loadAsync(url)).scene;
const head = findBone(robot, /^head$/i);
const face = new FaceMesh({ style: 'hologram', preset: 'cyan' });
attachFace(head, face, { at: [0, 0.0045, 0.0152], size: 0.44 });
