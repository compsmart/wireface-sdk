Build your own character

A snowman, from three.js primitives and a FaceMesh. The face brings the head: its size, its skull and its colour. face.bounds says where the eyes, brow, ears and the top of the head are, so the hat, the scarf and the coal can be put in the right places; anything added to face.head moves with it.

const face = new FaceMesh({ style: 'sculpt', size: 0.26,
  colors: { skin: '#f4f8ff', lips: '#7d8fb3', iris: '#1e293b' } });
attachFace(head, face);           // head: a Group on the body
const { skull } = face.bounds;    // also eyes, ears, brow, nose, mouth, chin...
hat.position.set(0, skull.center.y + skull.radius.y * 0.8, skull.center.z);
face.head.add(hat);               // moves with every nod
body.material = face.skinMaterial();   // the face's own colour
