Talk with a character

A live conversation with Gemini Live, through Wireface 2D's Conversation, which drives any face: here a three.js character. Its replies stream in as audio, lip-synced as they play, and the model shows its feelings on the face with an express tool.

This needs a Gemini API key on the dev server: set GEMINI_API_KEY in the backend environment and run npm start again. The key stays in the server; the page asks it for a one-use token.

const talk = new Conversation(character.face, {
  audio: () => unlockAudio(),
  character: () => ({ name: 'Unit-7', voice: 'Puck',
    persona: 'You are Unit-7, a cheerful robot...' }),
  onCaption: ({ who, text }) => ...,
});
await talk.start();
talk.setMic(true);
