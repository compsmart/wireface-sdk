Independent example · runtime only

A character. Your application.

Load a .wireface.json exported by Creator. This application imports only the runtime. It needs no account or external service.

Loading Sarah…

import { createFace, loadCharacter } from '@wireface/sdk';
const face = createFace(canvas);
await face.useCharacter(await loadCharacter('/characters/sarah.wireface.json'));
face.express('happy');
face.listenTo(audioContext, audioSource);
