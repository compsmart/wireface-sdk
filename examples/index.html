Wireface SDK: examples

Small pages, one feature each: view their source. Serve this folder over http(s) (npm start does).

  • 3D faces

    @wireface/sdk: a wireframe, sculpted or photo-skinned face on a canvas.

  • 2D faces

    @wireface/sdk/2d: any picture of a face, brought to life.

  • three.js

    @wireface/sdk/three: faces on the heads of three.js characters (run npm install first, for three).
