Wireface SDK: examples

Small pages, one feature each: view their source. Serve this folder over http(s) (npm start does).

  • Animate webpage images

    Free, silent expressions and eye movements: every image, a class, or a carousel.

  • Create a character on the device

    A photo rigged locally as 3D or 2D, with no key or upload; save it as .wireface.json.

  • Hosted AI rigging

    Drawn and stylised faces, detected on wireface.dev: progress, cancellation, export, reload and local audio.

  • Offline fixed-frame photo mapping
  • Portable character playback

    Load exported .wireface.json files using only the runtime; local audio lip-sync included.

  • 3D faces

    @wireface/sdk: a wireframe, sculpted or photo-skinned face on a canvas.

  • 2D faces

    @wireface/sdk/2d: any picture of a face, brought to life.

  • three.js

    @wireface/sdk/three: faces on the heads of three.js characters (run npm install first, for three).
